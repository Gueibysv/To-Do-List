# 📋 To-Do List

Este é um projeto simples de uma **lista de tarefas (To-Do List)** desenvolvido como prática de programação web, utilizando apenas **HTML, CSS e JavaScript**. A aplicação permite que o usuário adicione, marque como concluída e remova tarefas do dia a dia de forma simples e intuitiva.

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de reforçar os conhecimentos adquiridos na disciplina de Desenvolvimento Web e melhorar a lógica de programação no uso do JavaScript puro (sem frameworks). Além disso, buscou-se aplicar boas práticas de estruturação com HTML e estilização com CSS.

## 🛠️ Tecnologias Utilizadas

- **HTML5** – Estrutura básica da página.
- **CSS3** – Estilização da interface.
- **JavaScript** – Funcionalidade da lista de tarefas (DOM, eventos, localStorage).

## 🧠 Funcionalidades

- ✅ Adicionar uma nova tarefa.
- ✅ Marcar/desmarcar tarefa como concluída.
- ✅ Remover tarefa da lista.
- ✅ Salvar tarefas automaticamente no navegador com `localStorage`.
